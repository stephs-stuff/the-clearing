# Design philosophy

Clarity for today. Continuity for tomorrow.

- Reduce cognitive load; shallow navigation and progressive disclosure.
- Capture first, organize later. Only a task title is required.
- Distinguish deadlines from intentions; no guilt or streak pressure.
- AI proposes; the user decides. No silent changes.
- Modern eclectic boho with midcentury influences: peacock blue, spring grass, warm ivory, walnut and raspberry plum. Clean sans serif functional text; restrained expressive accents. Space before borders. Accessible contrast and keyboard navigation.
- Private data stays outside public source code. No secrets in frontend code.

## Command Central

Command Central is a daily staging area, not an exhaustive dashboard. It supports orienting, setting intentions, assembling tasks and a temporary toolkit of relevant links, documents, notes and resources, then engaging with the day.

## Continuity as a core design goal

Help users maintain continuity between intentions and action while preserving curiosity, spontaneity and autonomy. With explicit permission, future assistance may learn routines, recurring commitments, planning patterns and preferences from actual behavior. Offer optional checkpoints, re-entry support and suggestions; distinguish a deliberate change of priorities from an unintentional diversion without assuming either. Never diagnose, shame, enforce routines or silently rearrange plans. Learned patterns should be inspectable, correctable, optional and deletable. Pattern learning is a future capability, not implemented in the prototype.
