# Roadmap

1. Visual prototype and feedback.
2. Secure Supabase schema, authentication, permissions and tests.
3. Persistent inbox, tasks, lists and planner.
4. Project continuity and preferences.
5. Notebook and resource library.
6. Vaktari (the Scout): server-side AI integrations with user approval.
7. Optional integrations and modules.

Order is provisional. Do not introduce advanced features before the core is useful.

## First Flight — initial experience milestone

Build one complete daily loop before expanding the system. Prototype with clearly labeled fictional data, then connect private persistence and AI through authenticated server-side services.

- Morning: Vaktari opens with a concise observation-led conversation; user confirms up to three fresh priorities; assemble Command Central.
- Working: priority workspace, optional quiet check-ins, quick Park a Thought capture with supporting notes and return to original context.
- Closing: reflect on progress, preserve the thread, set the table for tomorrow, and prepare the next activity (including gym transitions).
- Friday: close the workweek and prepare Monday; personal reflection optional; protect Sunday from unsolicited work prompts.
- Re-entry: ask optionally about absence, offer adaptation, no guilt or forced catch-up.

Vaktari is a female fictional dragon and wise counselor. Maintain stable principles, human agency, epistemic humility, constructive challenge, and an evolving character revealed gradually. No guilt for absence or claims of emotional need. Later: original voice, optional growl/fire animation with sound and reduced-motion controls, intellectual conversations and deeper reflection in The Overlook. These are not prerequisites for First Flight.
